# 霓虹貪吃蛇 (Neon Snake)

一個單檔、零相依的霓虹風格貪吃蛇網頁遊戲。

## 如何遊玩

直接用瀏覽器開啟 `index.html` 即可，不需要安裝或建置。

## 操作方式

| 動作 | 鍵盤 | 手機 |
| --- | --- | --- |
| 移動 | 方向鍵 / WASD | 在畫面上滑動 |
| 暫停 / 繼續 | 空白鍵 | — |
| 開始 / 再玩一次 | 空白鍵 / Enter | 點「開始遊戲」按鈕 |

## 規則

- 吃到粉紅色的食物得 1 分。
- 每吃 5 顆，速度提升一級。
- 撞到牆壁或自己的身體即遊戲結束。
- 最高分會儲存在瀏覽器的 `localStorage` 中。
